# Agent instructions

Read **[CLAUDE.md](CLAUDE.md)** first. It is the instruction file for AI coding agents working
in this repo - architecture, the 21 standing rules, and the checks that must be clean before a
pull request - and it is the single source of truth. This file exists only so an agent that
looks for `AGENTS.md` is pointed at it, and so one rule isn't missed by skimming:

**This repository is PUBLIC.** Everything you commit - code, comments, commit messages, test
fixtures - is world-readable the moment it's pushed, and a commit message cannot be retracted
by a later commit; the only remedy is a history rewrite. Before committing, read *This
repository is PUBLIC* in [CLAUDE.md](CLAUDE.md) (standing rules 18-21) for what must never
appear in a tracked file. [CONTRIBUTING.md](CONTRIBUTING.md) states the same rules for human
contributors.
